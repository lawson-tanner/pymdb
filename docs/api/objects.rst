``mdb.objects``
=================

The OMF/Avid class vocabulary. Laid out as a package, mirroring pyavb's
module layout: ``base``, ``attributes``, ``locators``, ``descriptors``,
``misc``, ``components``, ``trackgroups``, ``effects``, ``parameters``,
``trackers``, ``media``. Everything is re-exported from ``mdb.objects``
(and from ``mdb`` itself), so ``mdb.Mob`` and ``mdb.objects.Mob`` are the
same class.
